# 조기유학·교환학생

| 형태 | 시기 | 장단점 |
|---|---|---|
| 단기 캠프·어학연수 | 초등~중 방학 | 맛보기, 동기 부여 |
| 교환학생 (미국 공립 등) | 고1 전후 1년 | 비교적 저렴, 학교 선택권 적음 |
| 보딩스쿨 | 중3~고 | 명문대 진학 경로, 고비용, 정서적 부담 |
| 부모 동반 유학 | 초등~ | 가족 분리 문제 |

## 부부가 따져볼 것
- 아이의 독립성·정서적 준비
- 가족 분리(기러기) 감수 여부
- 복귀 시나리오 (국내 대학 특례 요건 충족 여부)
