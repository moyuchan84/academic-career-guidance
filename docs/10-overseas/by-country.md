# 국가별 대학 입시 요건

| 국가 | 주요 평가 | 특징 |
|---|---|---|
| 미국 | 고교 성적(GPA), SAT/ACT(학교별 선택), AP, TOEFL, 에세이, 비교과 활동 | 전인적 평가, 9~12학년 기록 |
| 영국 | A-level 또는 IB, UCAS 지원, 전공 에세이(Personal Statement) | 전공을 입학 때 확정 |
| 캐나다 | 고교 성적 중심, IB/AP 인정 | 상대적으로 성적 중심 |
| 호주 | ATAR 또는 IB, 파운데이션 과정 | |
| 홍콩·싱가포르 | IB·A-level, 입학시험·면접 | 아시아 명문 |
| 일본 | EJU, 영어 트랙(국제 과정) | |

{: .warning }
> SAT 필수 여부 등은 대학마다 자주 바뀝니다. 고1 시점에 최신 요건 확인.
