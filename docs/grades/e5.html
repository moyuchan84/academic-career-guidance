5학년의 1년 흐름

이번 학년 과목별 단원 한눈에

과목 탭을 고르면 5학년 단원이 학기별로 나옵니다. 단원 이름을 누르면 해당 단원 지도가 열려요(핵심 개념, 집에서 하는 활동, 게임, 자세한 지도안). 여기서는 한 줄 목표 · 핵심 · 걸림돌만 짧게 봅니다.

5학년 국어는 글의 구조로 요약하기, 토의·토론, 기행문·설명하는 글이 중심입니다. 교과서마다 단원 이름과 순서가 다르니 아래는 대표 단원이에요.

1학기

  • 1. 자연수의 혼합 계산🎮 게임📘 지도안

    덧셈·뺄셈·곱셈·나눗셈과 ( )가 섞인 식의 계산 순서

    핵심계산 순서 : () 안 → 곱셈·나눗셈 → 덧셈·뺄셈

    걸림돌무조건 앞에서부터 계산 (10 − 2 × 3 = 24) → 순서 번호 표시

  • 2. 약수와 배수🎮 게임📘 지도안

    약수·배수, 공약수·최대공약수, 공배수·최소공배수

    핵심약수 : 어떤 수를 나누어떨어지게 하는 수(12의 약수 1, 2, 3, 4, 6, 12)

    걸림돌약수를 빠뜨림(특히 1과 자기 자신) → 짝으로 찾기

  • 3. 규칙과 대응🎮 게임📘 지도안

    두 양 사이의 대응 관계를 표와 식(○, △)으로 나타낸다

    핵심한 양이 변할 때 다른 양이 일정한 규칙으로 변하는 관계

    걸림돌표의 앞 두 칸만 보고 규칙을 정해요 → 셋째·넷째 칸에도 맞는지 확인

  • 4. 약분과 통분🎮 게임📘 지도안

    크기가 같은 분수, 약분, 기약분수, 통분과 크기 비교

    핵심크기가 같은 분수 : 분모·분자에 같은 수를 곱하거나 나누어도 크기는 같다(1/2 = 2/4 = 3/6)

    걸림돌분자·분모에 같은 수를 더해도 된다고 생각 (1/2 = 2/3) → 그림으로 확인

  • 5. 분수의 덧셈과 뺄셈🎮 게임📘 지도안

    분모가 다른 분수(대분수 포함)의 덧셈과 뺄셈

    핵심통분한 뒤 분자끼리 더하고 뺀다: 1/2 + 1/3 = 3/6 + 2/6 = 5/6

    걸림돌분모끼리 더하고 분자끼리 더함 (1/2 + 1/3 = 2/5) → 1/2보다 작아지는 모순 보여 주기

  • 6. 다각형의 둘레와 넓이🎮 게임📘 지도안

    직사각형·평행사변형·삼각형·마름모·사다리꼴의 넓이

    핵심둘레(선의 길이, cm)와 넓이(면의 크기, cm²) 는 다르다

    걸림돌넓이 단위를 cm로 쓰거나 1 m² = 100 cm²로 착각 → 100 × 100 = 10000

2학기

  • 1. 수의 범위와 어림하기🎮 게임📘 지도안

    이상·이하·초과·미만, 올림·버림·반올림

    핵심이상·이하 는 그 수를 포함(●), 초과·미만 은 포함하지 않음(○)

    걸림돌이상과 초과 혼동 → 경계의 수 하나로 “포함? 불포함?” 확인

  • 2. 분수의 곱셈🎮 게임📘 지도안

    (분수)×(자연수), (자연수)×(분수), (분수)×(분수)

    핵심(분수) × (자연수) = 같은 분수를 여러 번 더하기

    걸림돌곱셈 결과가 항상 커진다고 생각 → 1보다 작은 수를 곱하는 예

  • 3. 합동과 대칭🎮 게임📘 지도안

    합동인 도형, 선대칭·점대칭 도형

    핵심합동 : 모양과 크기가 같아 완전히 겹치는 도형, 대응변 길이·대응각 크기가 같다

    걸림돌크기가 다른 닮은 도형도 합동이라 함 → “완전히 겹쳐?”

  • 4. 소수의 곱셈🎮 게임📘 지도안

    (소수)×(자연수), (자연수)×(소수), (소수)×(소수)와 소수점 위치

    핵심0.3 × 4 = 0.3을 4번 더하기 = 1.2

    걸림돌소수점 위치를 덧셈처럼 맞춤 (0.3 × 0.4 = 1.2) → 분수로 바꿔 확인

  • 5. 직육면체🎮 게임📘 지도안

    직육면체·정육면체의 구성 요소, 겨냥도, 전개도

    핵심직육면체 : 직사각형 6개로 둘러싸인 도형 / 정육면체 : 정사각형 6개

    걸림돌전개도를 머릿속으로만 접다 틀림 → 실제로 접기

  • 6. 평균과 가능성🎮 게임📘 지도안

    평균을 구하고 해석하며, 일이 일어날 가능성을 말과 수로 나타낸다

    핵심평균 = 자료 값을 모두 더해 자료 수로 나눈 값 = 고르게 했을 때의 값

    걸림돌평균을 가운데 값으로 오해 → 블록 옮기기

약분·통분 대비: 분수 고비 넘기

5학년 1학기 수학은 한 줄로 이어진 사슬입니다. 아래 지도에서 단원을 누르면 그 단원에 필요한 앞 단계가 함께 표시돼요. 막히는 곳이 있으면 한 칸씩 거슬러 올라가면 됩니다.

2월 (4학년 겨울방학)

기초 체력 점검

곱셈구구 거꾸로·섞어서 1분, 두 자리 ÷ 한 자리 나눗셈 10문제. 느리면 이 2주가 5학년 1학기 전체를 편하게 합니다. 4학년 분수 덧셈·뺄셈 한 번 훑기.

3월

약수와 배수: 짝으로 찾기

"12의 약수 대결": 1×12, 2×6, 3×4를 짝 지어 적기. 배수 두 줄을 나란히 적어 처음 겹치는 수(최소공배수) 찾기. 저녁 10분이면 충분해요.

4~5월

약분·통분: 눈으로 먼저

색종이 반 접기 → 또 반 접기로 1/2 = 2/4 = 4/8. 계량컵 2/4컵 = 1/2컵. 식은 그다음. 단원평가 전 "12/18을 기약분수로, 3/4과 5/6 비교" 두 문제로 확인.

6월

분모가 다른 덧셈·뺄셈

통분 → 분자끼리 → 약분 → 대분수로. 네 단계를 소리 내어 말하며 풀기. 대분수 뺄셈에서 받아내림이 나오면 그림으로 1을 쪼개 보여 주세요.

여름방학

분수 복습 2주

새 진도보다 1학기 분수 단원 문제집 다시 풀기(틀린 문제만). 2학기 분수의 곱셈이 훨씬 가벼워집니다.

이런 신호면 괜찮아요

  • 틀려도 "어디서 틀렸는지" 스스로 찾는다
  • 1/2 = 2/4를 그림이나 말로 설명한다
  • 최대공약수로 한 번에 약분하려고 시도한다

이런 신호면 한 칸 뒤로

  • 약수를 찾는 데 한참 걸린다 → 곱셈구구·나눗셈
  • 1/3이 1/4보다 작다고 한다 → 3학년 분수 개념
  • 분모끼리 더한다 → 크기가 같은 분수부터 다시

문제집 권수보다 "왜 그렇게 했어?" 한 번이 더 효과적입니다. 5분 게임은 약분과 통분 단원의 "크기가 같은 분수", "분모가 다른 분수 비교"를 아이와 함께 해 보세요.

2학기 수학은 분수·소수의 곱셈, 합동과 대칭, 직육면체처럼 계산과 공간 감각이 섞입니다. 전개도는 실제 상자를 펼쳐 보는 것이 문제집 10장보다 낫습니다. 한국사는 연도 암기보다 시대 순서와 원인·결과를 말로 설명할 수 있는지 확인하세요.

이렇게 읽어요

  • 과목별로 "~할 수 있음" 문장을 찾아 아이의 강점부터 읽기

하지 않아요

  • 형제·친구 통지표와 비교
  • 표현 하나에 과잉 해석 ("보통" = 실패 아님)

부모"엄마 집인데 어디든 못 들어가니?"

부모"맞아, 노크 안 한 건 내 잘못이야. 이제부터 노크하고 대답 들을게. 대신 저녁 먹자고 부를 땐 대답은 해 줘."

아이"…알았어."

사생활 요구는 자라는 신호입니다. 노크와 대답을 서로의 약속으로 바꿔 주세요. 문은 닫혀도 대화 채널(저녁 식탁, 차 안, 산책)은 열어 둡니다.

아이"분수 진짜 싫어. 나는 수학 머리가 아닌가 봐."

부모"그러니까 문제집 더 풀라고 했잖아."

부모"분수가 5학년에서 제일 어려운 단원이래. 어른들도 헷갈려. 어디부터 막혔는지 같이 찾아볼까? 색종이 하나 가져와 봐."

아이"통분할 때 분자는 그대로 두는 거 아니야?"

부모"오, 거기였구나. 그거 하나면 금방 풀려."
