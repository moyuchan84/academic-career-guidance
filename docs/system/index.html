10년 뒤에도 통할 것

  • 긴 글을 읽고 이해하는 힘
  • 수학적으로 생각하는 습관 (개념 → 이유 설명)
  • 영어로 읽고 쓰는 능력
  • 스스로 계획하고 꾸준히 하는 힘, 그리고 공부 정서

초등 시기의 목표는 "제도 대비"가 아니라 기초 체력입니다. 제도는 알고만 있고, 실제 결정은 해당 학년이 되었을 때 최신 정보로 부부가 함께 내립니다. 결정은 결정 로그에 남겨요.
