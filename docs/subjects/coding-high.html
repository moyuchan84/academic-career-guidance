    같은 글자가 이어지면 “글자+개수”로 줄이는 런 길이 부호화(RLE)를 만들자.

    1. 같은 글자가 몇 개 이어지는지 센다.
    2. “글자+개수”를 붙이고 다음 글자로 건너뛴다.
    3. ABABAB는 오히려 길어져요. 데이터 특성에 따라 효과가 달라요.
    def rle(s):
    out, i = "", 0
    while i < len(s):
        j = i
        while j < len(s) and s[j] == s[i]:
            j += 1
        out += s[i] + str(j - i)
        i = j
    return out
print(rle("AAAAABBB"))   # A5B3

    1. 상태 = 장소, 행동 = 이동, 목표 = 역.
    2. 1단계 거리부터 넓혀 가며 본 곳은 건너뛴다.

    from collections import deque
graph = {"집": ["학교", "공원"], "학교": ["도서관"], "공원": ["역"], "도서관": ["역"], "역": []}
def bfs(start, goal):
    q, seen = deque([[start]]), {start}
    while q:
        path = q.popleft()
        if path[-1] == goal:
            return path
        for nxt in graph[path[-1]]:
            if nxt not in seen:
                seen.add(nxt)
                q.append(path + [nxt])
print(bfs("집", "역"))   # ['집', '공원', '역']
