수학 · 중학교 단원 지도

중학교부터 부모는 선생님이 아니라 “질문하는 청중”이 됩니다. 이 페이지는 중1~중3 단원마다 아이가 꼭 이해해야 할 개념, 부모가 던질 질문, 막혔을 때 돌아갈 초등 단원을 정리했어요. 아이 교과서 목차를 옆에 펴 놓고 해당 단원만 열어 보세요.

막히면 거꾸로

학년별 단원 지도

중1 수학은 “산수에서 수학으로” 넘어가는 해예요. 음수와 문자가 등장해 계산의 규칙이 바뀌고, 도형은 “재는 것”에서 “성질을 말하는 것”으로 바뀝니다. 자유학기(또는 자유학년)로 지필 시험이 없거나 적을 수 있어 구멍이 드러나지 않은 채 지나가기 쉬운 해이니, 집에서 “설명하기”로 점검해 주세요.

1학기

소인수분해자연수를 소수의 곱으로 쪼개고 최대공약수·최소공배수 구하기

핵심 개념

  • 소수: 약수가 1과 자기 자신 2개뿐인 수. 합성수: 약수가 3개 이상. 1은 소수도 합성수도 아님
  • 거듭제곱 표현(2×2×2 = 2³, 밑과 지수)
  • 소인수분해: 합성수를 소인수만의 곱으로 나타내기. 곱하는 순서를 무시하면 결과는 한 가지뿐
  • 최대공약수 = 공통인 소인수를 지수가 작은 쪽으로 곱한 것, 최소공배수 = 모든 소인수를 지수가 큰 쪽으로 곱한 것
  • 서로소: 최대공약수가 1인 두 수

이렇게 지도해요

  1. 정의부터 말하게 해요. “소수가 뭔지 한 문장으로 말해 줄래? 그럼 1은?”
  2. 72를 가지치기(나무 그림)로 쪼개는 과정을 소리 내어 설명하게 하고, 부모는 받아 적기만 해요.
  3. 초등식(공약수로 나누기)과 소인수분해식 두 방법으로 같은 문제를 풀게 한 뒤 “두 방법이 왜 같은 답이 나올까?”
  4. 틀린 문제는 “쪼개기에서 틀렸어, 지수 고르기에서 틀렸어?” 어느 단계인지만 표시하게 해요.
집에서 하는 활동
  • 버스 두 대가 12분, 18분 간격으로 같이 출발했어요. 다음에 동시에 출발하는 건 몇 분 뒤? (최소공배수 36분)
  • 사탕 48개와 젤리 36개를 남김없이 똑같이 봉지에 나누면 최대 몇 봉지? (최대공약수 12)
  • 1~100 수표에 함께 색칠하며 에라토스테네스의 체로 소수 찾기
자주 틀리는 곳
  • 1을 소수라고 함 → “약수가 몇 개야?”로 정의에 돌아가기
  • 2는 짝수라서 소수가 아니라고 생각 → 2는 유일한 짝수 소수
  • 최대공약수에서 지수가 큰 쪽을 고름(최소공배수와 혼동) → “둘 다 공통으로 가진 만큼만” 말로 정리
확인 질문

    답 보기아니요. 약수가 1 하나뿐이라 소수(약수 2개)의 정의에 맞지 않아요.
  2. 60을 소인수분해하세요.
    답 보기2²×3×5
  3. 2²×3과 2×3²×5의 최대공약수와 최소공배수는?
    답 보기최대공약수 2×3 = 6, 최소공배수 2²×3²×5 = 180

정수와 유리수음수를 이해하고 부호가 있는 수의 사칙계산 하기

핵심 개념

  • 양수·음수: 기준(0)에 대해 서로 반대 방향의 양
  • 정수(양의 정수, 0, 음의 정수) ⊂ 유리수(분수 a/b 꼴, b≠0)
  • 절댓값 = 수직선에서 0까지의 거리. 음수끼리는 절댓값이 클수록 작다
  • 뺄셈은 빼는 수의 부호를 바꾸어 더하기. 곱셈·나눗셈은 음수가 짝수 개면 +, 홀수 개면 −
  • 계산 순서: 거듭제곱 → 괄호 → 곱셈·나눗셈 → 덧셈·뺄셈

이렇게 지도해요

  1. 생활 질문으로 열어요. “영하 3도에서 5도 오르면 몇 도야?”
  2. 수직선을 그리게 하고 “−3 + 5를 수직선에서 보여 줄래?” 이동으로 설명하게 해요.
  3. “빼기 음수가 왜 더하기가 될까?” 빚(−)을 없애 주면 재산이 늘어나는 이야기로 스스로 말해 보게.
  4. (−)×(−)=(+)는 패턴 표로: 3×(−2), 2×(−2), 1×(−2), 0×(−2) … 다음은? 커지는 규칙을 아이가 찾게 해요.
  5. 오답을 “부호 실수 / 계산 순서 실수 / 분수 계산 실수”로 나눠 표시해요. 분수 실수가 많으면 초등으로.
집에서 하는 활동
  • 엘리베이터: 지하 2층에서 5층 올라가면? 5층에서 7층 내려가면? (층수)
  • 가계부·통장 놀이: 입금 +, 출금 −로 한 달 용돈 흐름 기록
  • 일기예보의 최고·최저 기온 차 구하기 (예: 3도와 −4도의 차는 7도)
자주 틀리는 곳
  • −5 > −2라고 함 → 수직선에서 오른쪽에 있는 수가 크다
  • −3²과 (−3)² 혼동 → −9와 9. 괄호가 “무엇을” 제곱하는지 말로 확인
  • 뺄셈을 덧셈으로 바꿀 때 기호만 바꾸고 뒤 수의 부호는 그대로 둠
  • 분수 통분·약분이 느림 → 초5로 내려가 보충
확인 질문
  1. |−7|과 |3| 중 큰 것은?
    답 보기|−7| = 7
  2. (−2)×(−3)×(−1)은?
    답 보기음수가 3개(홀수)이므로 −6
  3. −3² − (−2)³을 계산하세요.
    답 보기−9 − (−8) = −9 + 8 = −1

초5~6 분수의 덧셈·뺄셈·곱셈·나눗셈 → 정수와 유리수 → 문자와 식, 일차방정식(모든 계산이 부호 위에서). 막히면: 초5 약분과 통분, 초6 분수의 나눗셈.

문자와 식문자로 수량을 나타내고 일차식을 계산하기

핵심 개념

  • 문자를 쓰면 여러 경우를 한 식으로 나타낼 수 있다
  • 곱셈 기호 생략 규칙: 수를 문자 앞에, 1은 생략, 같은 문자는 거듭제곱. 나눗셈은 분수 꼴로
  • 식의 값 = 문자에 수를 대입해 계산한 값(음수는 괄호에 넣어 대입)
  • 항·상수항·계수·차수, 일차식
  • 동류항끼리만 더하고 뺀다, 분배법칙 2(x+3) = 2x + 6

이렇게 지도해요

  1. “초등학교 때 □ 넣기 문제 기억나? 그 □에 이름을 붙인 게 x야.”로 연결해요.
  2. 생활 수량을 식으로 쓰게 해요. “한 개 x원짜리 과자 3개랑 500원짜리 음료 하나는?” → 3x + 500
  3. 대입해 보게: “과자가 1200원이면 얼마야?”
  4. 동류항: “사과 3개 + 배 2개 + 사과 1개를 간단히 말하면?” 말로 먼저, 식은 나중에.
  5. 오답은 괄호 앞 음수 분배 실수인지 먼저 확인해요.
집에서 하는 활동
  • 휴대폰 요금제를 식으로: 기본료 + (추가 1GB당 요금) × x
  • 레시피를 x인분으로 바꾸기(2인분 기준 재료 → x인분 식)
  • 가족 나이를 문자로: 내가 a살이면 동생은? 엄마는?
자주 틀리는 곳
  • 3x + 2 = 5x로 합침 → 문자가 다른 항(상수항)은 합칠 수 없음
  • −(x − 3) = −x − 3 → 괄호 안 모든 항에 −1을 곱하기
  • x × x를 2x로 씀 → x²
  • 음수를 대입할 때 괄호를 안 씀
확인 질문
  1. a × (−2) × b를 곱셈 기호를 생략해 쓰세요.
    답 보기−2ab
  2. x = −2일 때 3x² − x의 값은?
    답 보기3×4 − (−2) = 12 + 2 = 14
  3. 2(x − 3) − (3x − 1)을 간단히 하세요.

수와 식: 유리수와 순환소수 · 식의 계산유한소수·순환소수의 판별, 지수법칙과 다항식의 계산

2015 개정에서는 중2 첫 단원이 “유리수와 순환소수”였어요. 2022 개정에서는 순환소수를 다루는 깊이와 위치(중2 또는 중3 무리수 도입부)가 교과서마다 다르다는 안내가 있으니 목차로 확인하세요.

핵심 개념

  • 기약분수의 분모의 소인수가 2나 5뿐이면 유한소수, 아니면 순환소수
  • 순환소수는 모두 유리수(분수로 나타낼 수 있음)
  • 지수법칙: aᵐ×aⁿ = aᵐ⁺ⁿ, (aᵐ)ⁿ = aᵐⁿ, aᵐ÷aⁿ, (ab)ⁿ = aⁿbⁿ
  • 단항식의 곱셈·나눗셈(나눗셈은 역수의 곱)
  • 다항식의 덧셈·뺄셈, 이차식, 단항식 × 다항식

이렇게 지도해요

  1. “2³×2⁴가 왜 2⁷이야? 풀어 써 볼래?” 곱하는 개수를 세게 해요.
  2. (aᵐ)ⁿ과 aᵐ×aⁿ을 헷갈리면 규칙을 다시 외우지 말고 풀어 쓰기로 돌아가요.
  3. 계산기로 1/3, 1/7을 나눠 보며 “반복되는 부분이 어디야?”
  4. 틀린 문제는 부호·계수·지수 중 무엇을 놓쳤는지 표시
집에서 하는 활동
  • 종이 접기 두께: 한 번 접을 때마다 2배 → 10번이면 2¹⁰ = 1024겹
  • 계산기로 1/7의 순환마디 찾기(142857)
  • 두 배씩 늘어나는 세균 이야기로 지수 감각 키우기
자주 틀리는 곳
  • aᵐ×aⁿ = aᵐⁿ으로 씀
  • (−2a)³에서 부호나 계수를 세제곱하지 않음 → −8a³
  • 단항식 나눗셈에서 역수를 곱하지 않음
  • 기약분수로 만들지 않고 분모만 보고 유한소수를 판단
확인 질문
  1. 7/20은 유한소수인가요?
    답 보기20 = 2²×5라서 유한소수(0.35)
  2. (x²)³ × x를 간단히 하세요.
    답 보기x⁶ × x = x⁷
  3. 6a²b ÷ 2ab는?
    답 보기3a

일차부등식부등식의 성질로 일차부등식을 풀고 활용하기

핵심 개념

  • 부등호 <, >, ≤, ≥와 “초과·미만·이상·이하”
  • 부등식의 해: 부등식을 참이 되게 하는 x의 값 전체
  • 양변에 같은 음수를 곱하거나 나누면 부등호 방향이 바뀐다
  • 수직선 표시: 포함(●), 불포함(○)
  • 활용: 해가 자연수·정수여야 하는 조건 확인

이렇게 지도해요

  1. “3 < 5의 양변에 −1을 곱하면?” 직접 계산해 확인하게 해요.
  2. 규칙을 아이 말로 정리: “음수를 곱하면 왜 뒤집혀?” 수직선에서 좌우가 바뀌는 것으로.
  3. 활용 문제에서 “이상/초과” 같은 말에 동그라미 치게 해요.
  4. 마지막에 답이 문제 조건(개수는 자연수)에 맞는지 확인
집에서 하는 활동
  • 택배 무게 구간별 요금표 읽기
  • 용돈 예산: “간식을 x개 사고 버스비 1500원은 남겨야 해”
  • 놀이기구 키 제한 “○○cm 이상”을 부등식으로
자주 틀리는 곳
  • 음수로 나눌 때 부등호 방향을 안 바꿈
  • 이상/초과의 수직선 점(●/○)을 바꿔 씀
  • 해가 정수·자연수라는 조건을 무시
확인 질문
  1. −2x > 6의 해는?
    답 보기x < −3
  2. 3x − 1 ≤ 2x + 4의 해는?
    답 보기x ≤ 5
  3. 한 개 700원인 과자를 5000원 이하로 사면 최대 몇 개?
    답 보기700x ≤ 5000, x ≤ 7.14… → 7개

연립일차방정식미지수가 2개인 연립방정식을 가감법·대입법으로 풀기

핵심 개념

  • 미지수가 2개인 일차방정식의 해는 순서쌍이고 여러 개일 수 있다
  • 연립방정식의 해 = 두 방정식을 동시에 만족하는 순서쌍
  • 가감법(한 문자를 없애기), 대입법(한 식을 다른 식에 넣기)
  • 활용: 미지수 2개를 정하고 조건 2개로 식 2개 세우기

이렇게 지도해요

  1. “해가 왜 한 쌍만 남을까?” 각 식의 해를 표로 나열해 공통인 것을 찾게 해요.
  2. “이 문제는 가감법이 편해, 대입법이 편해? 왜?” 방법 선택의 이유를 말하게.
  3. 활용 문제: “모르는 게 두 개네. 각각 뭐라고 둘래?”
  4. 구한 해를 두 식 모두에 넣어 확인
집에서 하는 활동
  • 놀이공원 입장료: 어른 2명 + 아이 1명 = ○원, 어른 1명 + 아이 2명 = △원 → 각각 얼마?
  • 닭과 토끼 문제: 머리 10개, 다리 28개
  • 음료 두 종류 가격 맞히기 게임
자주 틀리는 곳
  • 가감법에서 한 식의 일부 항에만 수를 곱함
  • 대입할 때 괄호를 빠뜨려 부호 실수
  • x만 구하고 y를 안 구함
확인 질문
  1. x + y = 5, x − y = 1의 해는?
    답 보기x = 3, y = 2
  2. 2x + y = 7, y = x + 1의 해는?
    답 보기2x + x + 1 = 7 → x = 2, y = 3
  3. 닭과 토끼가 모두 10마리, 다리가 28개이면?
    답 보기닭 6마리, 토끼 4마리
연결

중1 일차방정식 → 연립방정식 → 일차함수(두 직선의 교점), 고1 연립이차방정식.

일차함수와 그래프함수의 뜻, 기울기·절편, 일차함수와 일차방정식의 관계

핵심 개념

  • 함수: x의 값 하나에 y의 값이 하나씩 정해지는 관계
  • 일차함수 y = ax + b (a≠0), 기울기 a = (y의 증가량)/(x의 증가량)은 항상 일정
  • y절편·x절편, y = ax의 그래프를 y축 방향으로 b만큼 평행이동
  • a > 0이면 오른쪽 위로, a < 0이면 오른쪽 아래로. 기울기가 같고 절편이 다르면 평행
  • 일차방정식 ax + by + c = 0의 그래프는 직선, 연립방정식의 해 = 두 직선의 교점

이렇게 지도해요

  1. 표 → 그래프 → 식, 세 가지 표현을 오가게 해요. “이 표에서 x가 1 늘면 y는 얼마 늘어?”
  2. “기울기가 초6 때 배운 비율이랑 같은 거야?” 연결을 아이가 말하게.
  3. 요금제 비교 문제를 식으로 세우고 그래프로 그려 교점을 찾게 해요.
  4. “이 교점은 무슨 뜻이야?” 두 요금이 같아지는 지점이라는 걸 말로.
집에서 하는 활동
  • 요금제 비교: 기본료가 높고 단가가 낮은 A vs 기본료가 낮고 단가가 높은 B. 몇 GB부터 A가 유리할까? (두 직선의 교점)
  • 물통에 물을 받을 때 시간과 물 높이 기록 → 그래프
  • 자전거 대여 요금(기본 + 시간당)을 식으로
자주 틀리는 곳
  • 기울기를 (x의 변화)/(y의 변화)로 거꾸로 계산
  • x절편과 y절편 혼동
  • 평행(기울기 같고 절편 다름)과 일치(둘 다 같음) 혼동
  • x = 2 같은 식을 일차함수라고 함
확인 질문
  1. 두 점 (1, 3), (3, 7)을 지나는 직선의 식은?
    답 보기기울기 (7−3)/(3−1) = 2, y = 2x + 1
  2. y = −3x + 6의 x절편은?
    답 보기y = 0을 넣으면 x = 2
  3. y = 2x + 1과 y = −x + 4의 교점은?
    답 보기2x + 1 = −x + 4 → x = 1, 교점 (1, 3)

삼각형의 성질이등변삼각형, 직각삼각형의 합동, 외심과 내심

핵심 개념

  • 이등변삼각형: 두 밑각의 크기가 같고, 꼭지각의 이등분선은 밑변을 수직이등분
  • 직각삼각형의 합동 조건: RHA(빗변과 한 예각), RHS(빗변과 다른 한 변)
  • 외심: 세 변의 수직이등분선의 교점, 세 꼭짓점까지 거리가 같다(외접원의 중심). 직각삼각형은 빗변의 중점
  • 내심: 세 내각의 이등분선의 교점, 세 변까지 거리가 같다(내접원의 중심)
  • 증명: 가정과 결론을 구분하고, 근거(합동 조건, 성질)를 쓰기

이렇게 지도해요

  1. 증명은 “왜냐하면…”으로 말하게 해요. 쓰기 전에 말로.
  2. “이 문제의 가정은 뭐고 결론은 뭐야?” 먼저 구분하게.
  3. 외심·내심이 헷갈리면: “외접원은 밖에서 꼭짓점을 지나는 원, 내접원은 안에서 변에 닿는 원” 그림 그리기
  4. 서술형 오답은 “빠진 근거 한 줄”을 찾게 해요.
집에서 하는 활동
  • 종이 삼각형을 접어 각의 이등분선·변의 수직이등분선 만들고 교점 찾기
  • “세 마을에서 같은 거리에 우물을 파려면?” (외심)
자주 틀리는 곳
  • 외심과 내심의 성질을 뒤바꿈
  • 둔각삼각형의 외심이 삼각형 밖에 있다는 것을 모름
  • 증명에서 결론을 근거로 사용
확인 질문
  1. 이등변삼각형의 꼭지각이 40°이면 한 밑각은?
    답 보기(180° − 40°) ÷ 2 = 70°
  2. 직각삼각형의 외심은 어디에 있나요?
    답 보기빗변의 중점
  3. 내심에서 세 변까지 거리가 같은 이유는?
    답 보기각의 이등분선 위의 점은 그 각의 두 변까지 거리가 같기 때문

  3. 활용 문제는 그림부터, 기준각에 표시
  4. 기준각이 바뀌면 “높이”와 “밑변”이 바뀐다는 걸 확인

원의 성질현과 접선의 성질, 원주각

원주각의 활용 범위(원에 내접하는 사각형 등)는 교과서마다 다룰 수 있는 깊이가 달라요. 학교 교과서 목차와 수행평가 범위를 확인하세요.

핵심 개념

  • 원의 중심에서 현에 내린 수선은 그 현을 이등분한다
  • 중심에서 같은 거리에 있는 두 현의 길이는 같다
  • 접선은 접점을 지나는 반지름과 수직, 원 밖의 한 점에서 그은 두 접선의 길이는 같다
  • 원주각 = 같은 호에 대한 중심각의 ½, 한 호에 대한 원주각은 모두 같다, 반원에 대한 원주각은 90°

이렇게 지도해요

  1. 컴퍼스로 원을 그리고 여러 위치에서 원주각을 각도기로 재어 “같아?” 확인하게
  2. “원주각이 왜 중심각의 반일까?” 이등변삼각형을 찾아 설명하게
  3. 중심각·원주각을 서로 다른 색으로 표시하는 습관
집에서 하는 활동
  • 원형 접시의 지름 찾기: 종이의 직각 모서리를 원 둘레에 대면 두 교점이 지름의 양 끝(반원의 원주각 90°)
  • 원형 테이블 둘레에 앉은 사람들이 같은 그림을 보는 각이 같은 이유 이야기
자주 틀리는 곳
  • 중심각과 원주각 혼동
  • 접선과 반지름이 수직이라는 것을 활용하지 못함
  • 같은 호인지 확인하지 않고 원주각이 같다고 씀
확인 질문
  1. 중심각이 100°인 호에 대한 원주각은?
    답 보기50°
  2. 지름에 대한 원주각은?
    답 보기90°
  3. 원 밖의 한 점에서 그은 두 접선의 길이는?
    답 보기같다
연결

중1 부채꼴, 중2 삼각형의 성질(외심) → 원의 성질 → 고1 원의 방정식.

통계: 산포도·상자그림·상관관계자료가 흩어진 정도, 상자그림, 산점도와 상관관계

2022 개정에서 상자그림이 새로 들어오고, 대푯값은 중1로 옮겨졌어요. 공학 도구를 쓰는 통계적 탐구(문제 설정 → 수집 → 분석 → 해석)도 강조됩니다.

핵심 개념

  • 편차 = 변량 − 평균, 편차의 합은 항상 0
  • 분산 = 편차²의 평균, 표준편차 = √분산. 클수록 흩어져 있다
  • 사분위수와 상자그림(최솟값, 제1사분위수, 중앙값, 제3사분위수, 최댓값)
  • 산점도, 양의 상관관계·음의 상관관계·상관관계 없음
  • 상관관계는 인과관계가 아니다

이렇게 지도해요

  1. “평균이 같은 두 반 중 어느 반 점수가 더 고르지?”로 산포도의 필요성을 말하게
  2. “편차의 합이 왜 늘 0이야?” 이유를 설명하게(평균의 뜻)
  3. 상관 ≠ 인과: 여름에 아이스크림 판매와 물놀이 사고가 함께 늘어나는 예로 “진짜 원인은?”
  4. 스프레드시트로 분산·상자그림을 직접 만들어 보게
집에서 하는 활동
  • 가족 키와 발 크기 산점도 그리기
  • 두 도시의 월별 기온 자료(기상청)로 표준편차 비교
  • 뉴스 기사 속 “○○와 관련 있다” 표현이 인과인지 상관인지 함께 따져 보기
자주 틀리는 곳
  • 편차를 제곱하지 않고 분산을 구함
  • 표준편차에서 제곱근을 빠뜨림
  • 상관관계를 인과관계로 해석
  • 상자그림의 상자 길이가 자료의 개수를 뜻한다고 오해
확인 질문
  1. 편차의 합은?
    답 보기항상 0
  2. 분산이 4이면 표준편차는?
    답 보기2
  3. 상자그림에서 상자(제1~제3사분위수)가 나타내는 것은?
    답 보기가운데 약 50%의 자료가 퍼져 있는 범위
연결
