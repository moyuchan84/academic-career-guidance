국어 · 중학교 단원 지도

중학교 국어는 ‘읽고 느끼는 국어’에서 개념으로 분석하는 국어로 바뀝니다. 부모가 직접 가르칠 필요는 줄어들고, 대신 설명하게 하고, 요약하게 하고, 질문하는 코치 역할이 중요해져요.

이 페이지 쓰는 법

1

학년군 1~3

중학교 국어 성취기준은 1~3학년이 하나의 학년군으로 묶여 있어요. 어느 학년에 어떤 단원을 두는지는 교과서마다 달라요.

2

시험 범위와 맞추기

학교 시험 범위가 나오면 해당 단원을 펼쳐 ‘핵심 개념’과 ‘확인 질문’으로 점검하세요.

3

아이가 선생님

‘이렇게 지도해요’는 부모가 가르치는 법이 아니라 아이에게 설명을 시키는 법이에요.

🎮

아이와 해 보기

단원마다 체험 연계와, 여러 단원에 개념 확인 게임(분류·짝 맞추기·퀴즈)이 들어 있어요. 시험 대비 문제가 아니라 “설명해 볼래?”로 이어지는 5분 대화 거리예요.

학습 놀이터 →

2022 개정 교육과정은 중학교에 2025년 중1부터 순차 적용돼요. 중학교 국어는 검정 교과서이고 성취기준이 1~3학년군으로 제시되기 때문에, 아래 중1·중2·중3 배치는 대표적인 배치 예시일 뿐입니다. 예를 들어 품사·음운·문장 성분이 몇 학년에 나오는지는 출판사마다 달라요. 학기 초 교과서 목차와 학교 평가 계획(학교 누리집·학교알리미)을 꼭 확인하세요.

중학교 국어 부모 역할

📖

독서 대화 주 1회

같은 책이나 기사를 두고 “핵심이 뭐야? 너는 동의해?” 두 질문. 관리가 아니라 대화로.

📝

요약·질문 루틴

교과서 비문학 글이나 기사 한 편을 문단 요지 → 3문장 요약 → 질문 1개. 주 2~3회, 15분.

🧑‍🏫

문법은 설명시키기

“동사랑 형용사 어떻게 구별해?” 부모가 모르는 척 물어보면 아이가 개념을 정리해요. 막히는 곳이 곧 복습할 곳.

✍️

서술형 대비

답을 ‘개념 이름 + 근거 + 효과’ 문장 틀로 쓰는 연습. 교과서 학습 활동이 곧 서술형 문제예요.

📺

교과서 · EBS

시험 대비는 교과서 본문과 학습 활동이 기본. 개념이 약하면 EBS 중학 강의로 보충해요.

학년별 단원 지도

중1은 개념어와 친해지는 해예요. 비유·상징, 소설의 갈등, 요약·설명 방법, 품사 같은 국어 개념어를 처음 체계적으로 배웁니다. 자유학기(대개 중1 한 학기)에는 지필 시험 부담이 줄어드는 대신 수행평가와 프로젝트가 많아 독서·토론 습관을 잡기에 좋아요.

1학기 (대표 배치)

비유와 상징 문학시의 표현 방법과 효과 해석

핵심 개념

  • 비유: 직유(~처럼), 은유(A는 B), 의인(사람처럼), 활유(생물처럼)
  • 상징: 구체적 대상이 추상적 의미를 대신(비둘기 → 평화). 비유와 달리 원관념이 드러나지 않음
  • 운율·심상(시각·청각·공감각)과 함께 시의 분위기를 만듦

이렇게 지도해요

  1. 아이에게 개념을 설명하게 하기: “은유랑 상징, 나한테 설명해 줄래?”
  2. 좋아하는 노래 가사에서 비유·상징 찾기
  3. 교과서 시 한 편: 원관념-보조관념 표 만들기
  4. “이 표현이 없으면 느낌이 어떻게 달라져?” 효과를 한 문장으로
집에서 하는 활동
  • 가사 분석 대화
  • 가족 사진 한 장을 상징 하나로 표현하기
  • 교과서 수록 시인의 다른 시 찾아 읽기
체험 연계
  • 장소윤동주문학관(서울 종로) — 교과서 수록 시인의 시에서 비유·상징 찾기, 근처 “시인의 언덕” 산책 (장소 더 보기)
  • 생활노랫말·광고 문구 속 비유 표현 모으기, 상징(비둘기·태극기) 대화
  • 책·영상도서관 청소년 시집 코너 — 한 편 골라 원관념·보조 관념 표 만들기
아이와 해 보기 개념 확인 5분 · 답을 고른 뒤 “왜 그렇게 생각해?”로 설명하게 해 주세요
자주 틀리는 곳
  • 은유와 상징 혼동 → 원관념이 문장 안에 있으면 은유
  • 표현 방법 이름만 외우고 효과를 못 씀 → 서술형은 효과가 핵심
확인 질문
  1. “내 마음은 호수요”의 표현 방법은?
    답 보기

    은유

  2. 은유와 상징의 차이는?
    답 보기

    은유는 원관념과 보조관념이 함께 드러나고, 상징은 원관념이 숨어 있어요.

  3. ‘십자가’가 희생을 뜻한다면 무엇?
    답 보기

    상징

연결

비유 표현(초5) → 비유·상징 → 반어·역설(중2)

소설의 구성 요소와 갈등 문학인물·사건·배경과 갈등으로 소설 읽기

핵심 개념

  • 구성 요소: 인물·사건·배경, 구성 단계(발단-전개-위기-절정-결말)
  • 갈등: 내적 갈등(마음속) / 외적 갈등(인물-인물, 인물-사회, 인물-운명)
  • 인물 유형: 주동·반동, 평면·입체

이렇게 지도해요

  1. “이 소설에서 가장 큰 갈등이 뭐야?” 한 문장으로 말하게 하기
  2. 구성 단계 5칸 표에 사건 배치
  3. 갈등이 해결(또는 해소 안 됨)되는 장면 찾기
  4. 인물 관계도 그리기
집에서 하는 활동
  • 가족 드라마 보며 갈등 유형 맞히기
  • 교과서 소설 원작 전편 읽기
  • 인물 관계도 벽보
체험 연계
  • 행사청소년 연극·뮤지컬 관람 — 발단부터 결말까지 갈등이 어떻게 커지는지 메모
  • 생활가족 드라마 한 편 보고 “가장 큰 갈등은? 내적? 외적?” 한 문장 대화
  • 책·영상교과서 수록 소설의 원작 전편을 도서관에서 찾아 읽기

요약하며 읽기 읽기글의 구조를 파악하고 핵심 정보 정리

핵심 개념

  3. 전체를 200자 안으로
  4. 부모에게 1분 설명 → 부모는 “그래서 핵심이 뭐야?” 한 번만

설명 방법 읽기·쓰기정의·예시·비교·대조·분류·분석·인과

핵심 개념

  • 정의(A는 B이다), 예시, 비교(공통점), 대조(차이점), 분류(기준으로 나눔), 분석(부분으로 나눔), 인과, 과정
  • 분류는 여러 대상을 묶기, 분석은 한 대상을 쪼개기
  • 설명 방법을 알면 글 구조와 요약이 쉬워짐

이렇게 지도해요

  1. 교과서 예문을 아이에게 “이건 어떤 설명 방법?” 물어보기
  2. 분류 vs 분석 차이를 집 안 물건으로(식기 분류 / 자전거 분석)
  3. 설명 방법 두 가지를 써서 한 문단 쓰기
  4. 틀린 것은 “왜 그렇게 봤어?” 먼저 듣기

2학기 (대표 배치)

품사 문법9품사를 형태·기능·의미로 분류

핵심 개념

  • 9품사: 명사·대명사·수사(체언) / 동사·형용사(용언) / 관형사·부사(수식언) / 조사(관계언) / 감탄사(독립언)
  • 동사(움직임) vs 형용사(상태): 현재형 ‘-는다/-ㄴ다’가 되면 동사(먹는다 ○, 예쁜다 ×)
  • 관형사는 체언을, 부사는 주로 용언을 꾸밈. 수사 vs 수 관형사(둘이 / 두 사람)

이렇게 지도해요

  1. 아이에게 설명시키기: “동사랑 형용사 구별하는 방법 알려 줘.”
  2. 짧은 문장 하나를 낱말별로 품사 카드 붙이기
  3. 헷갈리는 짝만 모은 오답 노트(수사/관형사, 동사/형용사)
  4. 시험 1주 전 교과서 예문만 반복

가정 학습 루틴

이 학년 가정 학습 루틴

주 3~4회 × 30분. 비문학(과학·경제·인문) 한 편 요약 + 모르는 개념어 정리. 문법은 중1~3 개념을 한 장 표로 정리해 아이가 부모에게 설명. 고입 이후엔 고등 단원 지도로.

학원과 함께 쓸 때

학원이 하는 것

  • 학교별 기출·내신 대비, 문법 개념 강의
  • 교과서 작품 해설, 서술형 첨삭
  • 고등 국어(문학 개념·비문학) 선행

부모가 집에서 할 것

  • 주 1회 독서 대화, 요약·질문 루틴 유지
  • “설명해 줄래?”로 개념 점검(학원 필기 확인이 아니라)
  • 시험 전 교과서 본문 소리 내어 읽기 권하기
  • 수면·휴식 지키기, 성적보다 과정 칭찬

중학 국어 학원은 “개념이 흔들릴 때, 아이가 원할 때” 검토해요. 고등 선행보다 긴 책 읽기가 먼저라는 게 우리 집 기준. 결정은 결정 로그에 남기고, 앞 단계는 초등 단원 지도, 다음 단계는 고등 단원 지도.
