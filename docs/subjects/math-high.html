수학 · 고등 단원 지도

고등 수학은 부모가 가르치는 과목이 아니에요. 대신 학습 관리자이자 좋은 질문자가 될 수 있습니다. 이 페이지는 고1 공통수학1·2 단원을 자세히, 고2~3 선택 과목을 간단히 정리하고, 단원마다 부모가 던질 수 있는 질문과 막혔을 때 돌아갈 중학 단원을 적었어요.

2022 개정 교육과정 기준입니다(고1은 2025년부터 적용). 고등 교과서는 검정이라 단원 이름·순서가 교과서마다 다르고, 공통수학1·2의 학기 배치와 선택 과목 개설은 학교마다 달라요. 여기 적은 것은 성취기준에 기반한 대표 단원이니 아이 교과서 목차와 학교 교육과정 편성표로 확인하세요. 첫째가 고등학생이 되는 2034년 무렵에는 교육과정이나 대입 제도가 다시 바뀌어 있을 수 있어요.

과목별 단원 지도

공통수학1은 보통 고1 1학기에 배워요(학교에 따라 다름). 중3 인수분해·이차방정식·이차함수가 거의 모든 단원의 도구입니다. 중학교 때보다 양과 속도가 크게 늘어 첫 중간고사에서 충격을 받는 학생이 많아요. 부모는 내용을 가르치기보다 “중3 도구가 빠르고 정확한가”를 확인해 주세요.

다항식의 연산다항식의 사칙연산과 곱셈 공식의 확장, 다항식의 나눗셈

핵심 개념

  • 내림차순·오름차순 정리, 다항식의 덧셈·뺄셈·곱셈
  • 곱셈 공식 확장: (a+b)³, a³ + b³ = (a+b)(a² − ab + b²), (a+b+c)²
  • 곱셈 공식의 변형: a² + b² = (a+b)² − 2ab
  • 다항식의 나눗셈 A = BQ + R (R의 차수 < B의 차수), 조립제법

  • “a² + b²을 a+b와 ab로 나타내는 이유가 뭘까? 어디에 쓰여?”

자주 틀리는 곳

  • 기초가 흔들리면 중3 다항식의 곱셈과 인수분해, 중2 식의 계산으로

항등식·나머지정리·인수분해항등식의 성질, 나머지정리와 인수정리, 복잡한 식의 인수분해

핵심 개념

  • 항등식: 모든 x에 대해 성립 → 계수비교법, 수치대입법
  • 나머지정리: f(x)를 x − a로 나눈 나머지는 f(a)
  • 인수정리: f(a) = 0이면 f(x)는 x − a로 나누어떨어진다
  • 삼차·사차식의 인수분해(인수정리 + 조립제법), 치환, a³ ± b³

부모가 던질 질문

  • “나머지정리를 쓰면 왜 직접 나누지 않아도 돼? A = BQ + R에 뭘 넣은 거야?”
  • “방정식이랑 항등식은 뭐가 달라?” (중1 개념이 다시 나와요)
  • “f(1) = 0인 걸 보고 어떤 인수를 찾은 거야?”
자주 틀리는 곳
  • 항등식과 방정식 혼동
  • x − a의 부호를 헷갈려 f(−a)를 계산
  • 인수분해가 느리면 중3 인수분해부터 속도 확인
확인 질문
  1. f(x) = x³ − 2x + 1을 x − 2로 나눈 나머지는?
    답 보기f(2) = 8 − 4 + 1 = 5
  2. x³ − 1을 인수분해하세요.
    답 보기(x − 1)(x² + x + 1)
  3. ax + b = 3x − 2가 x에 대한 항등식이면?
    답 보기a = 3, b = −2

다항식의 연산 → 나머지정리·인수분해 → 여러 가지 방정식, 미적분Ⅰ(다항함수의 그래프).

복소수와 이차방정식복소수의 뜻과 연산, 판별식, 근과 계수의 관계

핵심 개념

  • i² = −1, 복소수 a + bi(실수부·허수부), 켤레복소수
  • 복소수의 사칙연산, 음수의 제곱근 √(−a) = √a i
  • 판별식 D = b² − 4ac: D > 0 서로 다른 두 실근, D = 0 중근, D < 0 서로 다른 두 허근
  • 근과 계수의 관계: α + β = −b/a, αβ = c/a

부모가 던질 질문

  • “판별식이 음수면 이차함수 그래프로는 무슨 뜻이야?”
  • “두 근을 직접 구하지 않고 합과 곱을 아는 게 왜 편해?”
자주 틀리는 곳
  • √(−2) × √(−3) = √6으로 계산(실제는 −√6)
  • i의 거듭제곱 주기(4)를 놓침
  • 근의 공식이 흔들리면 중3 이차방정식
확인 질문
  1. i²⁰²⁶의 값은?
    답 보기2026을 4로 나눈 나머지가 2이므로 i² = −1
  2. x² + 2x + 5 = 0의 근은?
    답 보기x = −1 ± 2i
  3. x² − 3x + 2 = 0의 두 근의 합과 곱은?
    답 보기합 3, 곱 2

중3 제곱근·이차방정식 → 복소수와 이차방정식 → 이차방정식과 이차함수.

이차방정식과 이차함수그래프와 x축·직선의 위치 관계, 제한된 범위의 최대·최소

  1. y = x² − 2x + k의 그래프가 x축에 접하면 k는?
    답 보기D/4 = 1 − k = 0 → k = 1

    답 보기x² − 2x + 1 = 0, D = 0 → 접한다

중3 이차함수 → 이 단원 → 여러 가지 부등식(이차부등식), 미적분Ⅰ 최대·최소.

여러 가지 방정식과 부등식삼차·사차방정식, 연립이차방정식, 여러 가지 부등식

자주 틀리는 곳

연결

중2 일차부등식, 중3 이차방정식 → 이 단원 → 대수(지수·로그 방정식), 미적분Ⅰ.

경우의 수: 순열과 조합합·곱의 법칙, 순열 nPr과 조합 nCr

핵심 개념

  • 합의 법칙·곱의 법칙(중2의 확장)
  • 순열: 서로 다른 n개에서 r개를 뽑아 순서 있게 나열, nPr = n!/(n−r)!
  • 조합: 순서 없이 r개를 고르기, nCr = n!/(r!(n−r)!), nCr = nC(n−r)
  • 0! = 1, nP0 = 1, nC0 = 1

행렬행렬의 뜻과 덧셈·뺄셈·실수배·곱셈

행렬은 2015 개정 고등 수학에서 빠졌다가 2022 개정 공통수학1에 다시 들어왔어요. 선배들의 교재나 조언에는 없을 수 있어요. 역행렬 등 심화 내용은 다루지 않는 범위로 안내되어 있으니 교과서로 확인하세요.

핵심 개념

  • 행렬: 수를 직사각형 모양으로 배열, m × n 행렬, (i, j) 성분
  • 서로 같은 행렬, 덧셈·뺄셈·실수배
  • 행렬의 곱셈: 앞 행렬의 열의 수 = 뒤 행렬의 행의 수일 때만 가능, 결과는 (앞의 행 수) × (뒤의 열 수)
  • 곱셈은 일반적으로 교환법칙이 성립하지 않는다(AB ≠ BA)

부모가 던질 질문

  • “AB랑 BA가 다른 예를 하나 만들어 줄래?”
  • “스프레드시트 표도 행렬이라고 볼 수 있을까?”
집에서
  • 두 가게의 과일 값 표 × 우리 집 구매 수량 = 가게별 총액: 행렬 곱의 의미를 생활로
자주 틀리는 곳
  • 곱셈이 가능한 조건 확인 없이 계산
  • AB = BA라고 가정
  • 성분 위치(행·열) 혼동
확인 질문

    답 보기2 × 1 행렬

    답 보기(1 3 / 4 4)
  3. 행렬의 곱셈에서 AB = BA가 항상 성립하나요?
    답 보기아니요. 일반적으로 성립하지 않아요.
