# 선행 vs 심화 vs 복습

| 구분 | 의미 | 효과 | 위험 |
|---|---|---|---|
| **복습** | 배운 것 다지기 | 결손 방지 | 지루함 |
| **심화** | 같은 학년 개념을 깊게 | 사고력·응용력 | 좌절감 |
| **예습** | 다음 학기 미리 보기 (0.5~1학기) | 수업 자신감 | 거의 없음 |
| **선행** | 1년 이상 앞서 배우기 | 입시 시간 확보 | 이해 없는 진도, 번아웃, 학교 수업 흥미 저하 |

## 선행 판단 체크리스트
- [ ] 현재 학년 **심화** 문제를 70~80% 이상 스스로 푸는가
- [ ] 선행한 내용을 **남에게 설명**할 수 있는가
- [ ] 선행 때문에 독서·운동·수면 시간이 줄지 않았는가
- [ ] 아이가 "재미있다" 또는 최소 "할 만하다"고 하는가

→ 하나라도 "아니오"면 속도를 늦춘다.
