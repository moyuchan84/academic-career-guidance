# 교육특구 선행 실태 (대치·목동·중계 등)

{: .warning }
> 아래는 흔히 알려진 경향이며 아이·학원마다 편차가 큽니다. **참고용이지 따라야 할 기준이 아닙니다.**

## 수학
| 학년 | 흔한 진도 (상위권 기준) |
|---|---|
| 초1~3 | 사고력 수학 + 교과 1년 선행 |
| 초4~5 | 중등 수학 시작 |
| 초6 | 중등 완료 → 고1 공통수학 |
| 중1~2 | 고등 수학 1~2회독 (미적분 포함) |
| 중3 | 고등 전 과정 반복, 고1 내신 대비 |

## 영어
- 영어유치원 → 초등 어학원 레벨 경쟁 → 초6~중1에 수능 영어 수준 → 중학 내신·토플

## 과학
- 과학고·영재학교 목표: 초고학년~중학생 물리·화학 심화, 올림피아드

## 그 외
- 영재교육원(교육청·대학 부설) 선발 대비
- '초등 의대반' 등 초고속 트랙
- 이사(학군지) 시기: 보통 초3~초6 전후

## 부부가 함께 생각할 질문
- 이 속도가 **우리 아이**에게 맞는가, 불안 때문인가?
- 선행이 아닌 곳에 쓸 시간(독서, 운동, 놀이, 가족)은 충분한가?
- 수능이 절대평가 영어 + 개편 가능성이 있는 상황에서 무엇이 확실한 투자인가?
