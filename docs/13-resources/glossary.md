# 용어 사전

| 용어 | 뜻 |
|---|---|
| 선행 | 1년 이상 앞선 학년 내용을 미리 배우는 것 |
| 심화 | 같은 학년 내용을 더 어렵고 깊게 |
| 세특 | 학생부 '세부능력 및 특기사항', 과목별 교사 서술 |
| 학종 | 학생부종합전형 |
| 수능 최저 | 수시 합격에 필요한 최소 수능 등급 |
| 성취평가제 | A~E 절대평가 |
| 고교학점제 | 학생이 과목을 선택해 학점을 이수하는 제도 |
| 자유학기 | 중학교 한 학기 시험 없이 진로·활동 중심 |
| 자사고 | 자율형 사립고등학교 |
| 영재원 | 교육청·대학 부설 영재교육원 |
| IB | 국제 바칼로레아, 국제 공인 교육과정 |
| AP | 미국 대학 선이수 과목 |
| 특례입학 | 재외국민 대상 정원 외 전형 |
