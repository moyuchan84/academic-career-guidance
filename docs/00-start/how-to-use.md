# 사이트 사용법

## 페이지 수정하는 법
1. GitHub 저장소에서 해당 `.md` 파일 열기 → 연필 아이콘(Edit)
2. 수정 후 "Commit changes" → 1~2분 뒤 사이트에 반영

## 표시 규칙
- `{: .warning }` **확인 필요**: 해마다 바뀌는 제도 정보
- `{: .tip }` **우리 집 방침**: 부부가 합의한 결정
- `{: .note }` **메모**: 관찰·아이디어
