첫 주 체크리스트

아이 모드란?

부모 모드 (기본)

  • 제도·입시·사교육 정보, 부부 체크리스트와 메모
  • 워크북·자료실 같은 부모 전용 섹션
  • 아이 콘텐츠는 보이지 않아요

아이 모드

  • 오른쪽 위 토글 버튼으로 전환
  • 새싹이(마스코트), 스탬프, 퀴즈, 뒤집기 카드
  • 부모 전용 페이지는 "엄마 아빠 방" 안내로 가려져요

아이 모드는 시험·경쟁 이야기가 없는 놀이 공간입니다. 아이와 나란히 앉아 같이 눌러 보세요. 아이 혼자 두는 도구가 아니에요.

체크와 메모는 어디에 저장되나요?

📱

지금 이 브라우저에만

체크박스, 스탬프, 메모는 이 기기·이 브라우저에만 저장됩니다. 서버로 보내지 않아요.

👫

엄마 폰 ≠ 아빠 폰

엄마가 폰에서 체크한 것은 아빠 폰에 보이지 않습니다. 각자의 작업 메모장이라고 생각하세요.

🔗

함께 볼 기록은

GitHub에서 페이지 HTML을 직접 고치거나(모두에게 보임), 공유 메모 앱을 함께 쓰세요. 결정 로그는 JSON 내보내기/가져오기를 지원해요.

브라우저의 방문 기록·사이트 데이터를 지우거나 시크릿 창을 쓰면 저장된 체크와 메모가 사라질 수 있어요. 중요한 합의는 인쇄하거나 GitHub에 옮겨 두세요.
