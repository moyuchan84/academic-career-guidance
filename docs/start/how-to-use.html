사이트 사용법

이 사이트는 GitHub에 있는 HTML 파일로 만들어져 있어요. 코드를 몰라도 아래 조각을 복사해 글자만 바꾸면 같은 디자인으로 페이지를 고치거나 추가할 수 있습니다.

페이지 고치기 머리말 아이 모드 새 페이지 컴포넌트 모음 역할 분담

페이지 고치는 법

1

맨 아래 "이 페이지 수정하기 ↗"

각 페이지 맨 아래(부모 모드에서만 보여요) 링크를 누르면 GitHub 편집 화면이 열립니다. GitHub 로그인과 저장소 권한이 필요해요.

2

HTML 고치기

글자만 바꿀 때는 태그(< > 안의 내용)는 건드리지 말고 사이의 글만 고치세요. 새 블록이 필요하면 아래 컴포넌트 조각을 복사해 붙입니다.

3

Commit changes

무엇을 고쳤는지 한 줄 적고 저장합니다. 예) "초3 수학: 분수 단원 메모 추가"

4

1~2분 뒤 확인

GitHub Pages가 다시 만들어지면 사이트에 반영됩니다. 안 보이면 새로고침(캐시)을 해 보세요.

금지 사항: 마크다운 문법(#, 별표 두 개, 표 기호 |)은 쓰지 않습니다. 이중 중괄호나 중괄호+퍼센트 같은 템플릿 문법도 본문에 넣으면 빌드가 깨질 수 있어요. 모두 HTML로 씁니다.

머리말(front matter)

파일 맨 위 --- 두 줄 사이는 목차·검색·다음/이전 버튼에 쓰이는 정보예요. 제목을 바꾸면 목차 이름도 바뀝니다. parent는 상위 섹션 제목과 글자 하나까지 똑같아야 해요.

---
title: 초등 2학년              # 목차·검색·다음/이전에 보이는 이름
parent: 학년별 가이드            # 상위 섹션 제목 (섹션 첫 페이지는 생략)
nav_order: 2                   # 목차 순서 (숫자)
kid: true                      # 아이 모드 내용이 있을 때만
stage: root                    # 학년 페이지만: root·stem·branch·fruit
summary: 구구단 · 스스로 읽기     # 섹션 첫 페이지 카드에 보이는 한 줄
wide: true                     # 큰 도표가 있을 때 넓은 화면 (선택)
---
항목필수설명
title필수페이지 이름
parent하위 페이지섹션 첫 페이지의 title과 정확히 같게
nav_order필수같은 섹션 안에서의 순서
has_children, permalink섹션 첫 페이지예) has_children: true, permalink: /docs/workbook/
kid, kid_title선택아이 모드에 보일지, 아이 모드용 목차 이름
summary, stage, wide선택카드 한 줄 설명, 학년 단계 색, 넓은 화면

아이 모드: kid, .kid-only, .parent-only

kid: true

머리말에 넣으면 아이 모드 목차에 이 페이지가 나타나요. 없으면 아이 모드에서 "엄마 아빠 방" 안내로 가려집니다.

.kid-only

아이 모드에서만 보이는 블록. 반말·해요체, 짧은 문장, 새싹이 상자와 놀이 요소 2개 이상.

.parent-only

부모 모드에서만 보이는 블록. 제도·사교육·부부 체크리스트는 모두 여기에.

<div class="kid-only">
  <div class="kid-box">
    <div class="mascot" data-stage="root"></div>
    <div>
      <h3>안녕! 나는 새싹이야</h3>
      <p>오늘은 무엇을 탐험해 볼까?</p>
    </div>
  </div>
  <!-- 스탬프, 퀴즈, 뒤집기 카드 등 놀이 요소 2개 이상 -->
</div>

<div class="parent-only">
  <!-- 부모용 내용 -->
</div>

문장 중간에 짧게 넣을 때는 span class="kid-only-inline" / span class="parent-only-inline"을 씁니다.

새 페이지 추가하기

  1. GitHub에서 해당 폴더(예: docs/workbook/)로 가서 Add file → Create new file
  2. 파일 이름은 영어 소문자와 하이픈으로: summer-2027.html
  3. 아래 뼈대를 붙여 넣고 제목·parent·nav_order를 바꿉니다
  4. Commit changes → 1~2분 뒤 왼쪽 목차에 자동으로 나타나요
