# 국어·독서
{: .no_toc }

1. TOC
{:toc}

## 1. 큰 그림
- 모든 과목의 기초 = **읽고 이해하는 힘(문해력)**
- 수능 국어의 핵심은 긴 비문학 지문을 빠르고 정확하게 읽는 능력

## 2. 학년별 진도 계통도
| 시기 | 핵심 |
|---|---|
| 초1~2 | 한글 해득, 소리 내어 읽기, 그림일기 |
| 초3~4 | 중심 생각, 문단, 의견 글 |
| 초5~6 | 요약, 논설문, 매체 읽기, 토론 |
| 중학교 | 문법 체계, 문학 갈래, 비문학 구조 |
| 고1 | 공통국어1·2 |
| 고2~3 | 문학, 독서와 작문, 화법과 언어 등 → 수능 국어 |

## 3. 막히는 지점
- 초3: 교과 어휘(사회·과학 용어) 부족 → 이해력 저하
- 초5: 글밥 많은 책으로 넘어가지 못함 (학습만화에 머무름)
- 중2~고1: 비문학 독해 속도

## 4. 가정에서 할 수 있는 것
- **가족 독서 시간** (TV 끄고 20분)
- 저녁 식탁 대화: 뉴스 한 꼭지 이야기하기
- 독서록은 짧게 (한 줄 → 세 줄 → 한 문단)

## 5. 학습지·교재·앱
- 초등: 어휘력 문제집, 독해 문제집(초3~), 한자 어휘
- 중등: 비문학 독해, 문법 입문서
- 앱·서비스: 전자도서관, EBS

## 6. 체험·여행 연계
- 국립한글박물관, 지역 도서관 프로그램, 작가와의 만남(북토크)
- 문학관: 김유정문학촌(춘천), 박경리문학공원(원주) 등 교과서 작가 문학관

## 7. 선행 vs 심화: 적정선
- 선행보다 **다독 + 정독** 이 곧 선행
- 교육특구: 초등 독서·논술 학원, 중등 국어 학원(문법·비문학)이 일반적

## 8. 교육특구에서는
- 초등 독서논술 학원·방문 수업이 흔함
- 중학생 때 고등 국어(문학 개념어·비문학) 선행
- 수능 국어가 변별력이 커지면서 국어 학원 수요 증가
