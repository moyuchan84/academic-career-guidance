# 사회·역사·도덕
{: .no_toc }

1. TOC
{:toc}

## 1. 큰 그림
- 지리·일반사회·역사·도덕을 거쳐 고1 **통합사회**, 수능 통합탐구로 연결
- 경험과 배경지식이 곧 실력 → **여행의 효과가 가장 큰 과목**

## 2. 학년별 진도 계통도
| 시기 | 핵심 |
|---|---|
| 초1~2 | 통합교과(학교, 마을, 우리나라, 세계) |
| 초3 | 우리 고장 |
| 초4 | 우리 지역(시·도), 촌락과 도시 |
| 초5 | 국토, 인권과 법, **한국사** |
| 초6 | 정치, 경제, 세계 여러 나라 |
| 중학교 | 사회(지리·일반사회), 역사(한국사·세계사), 도덕 |
| 고등학교 | 한국사1·2, 통합사회1·2 → 선택(세계시민과 지리, 사회와 문화, 정치, 경제 등) |

## 3. 막히는 지점
- 초5 역사: 연대·인물이 섞임 → 연표 만들기
- 중학 경제·정치 개념어

## 4. 가정에서 할 수 있는 것
- 가족 **역사 여행**, 뉴스 함께 보기, 선거 때 투표소 동행
- 지도·지구본을 거실에

## 5. 학습지·교재·앱
- 한국사 만화(입문), 어린이 역사책, 한국사능력검정 기본
- 지리: 세계지도 퍼즐, 국기 카드

## 6. 체험·여행 연계
- 국립중앙박물관, 국립민속박물관, 경주·공주·부여, 강화도, 수원화성
- 서대문형무소역사관, 독립기념관, 전쟁기념관
- 국회·대법원·한국은행 화폐박물관

## 7. 선행 vs 심화: 적정선
- 선행 불필요, **여행과 독서로 배경지식** 쌓기가 최고의 선행

## 8. 교육특구에서는
- 한국사 강의, 중학 사회 내신 학원 정도, 비중 낮음
