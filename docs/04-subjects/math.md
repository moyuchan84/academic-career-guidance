## 1. 큰 그림
- 수능·내신에서 가장 영향력이 큰 과목, 동시에 **포기자가 가장 많은 과목**
- 계통성이 강해 **구멍 하나가 이후 전부를 무너뜨림** → 선행보다 결손 방지가 먼저

## 2. 학년별 진도 계통도
| 영역 | 초1~2 | 초3~4 | 초5~6 | 중학교 | 고등학교 |
|---|---|---|---|---|---|
| 수와 연산 | 100·1000까지 수, 덧뺄셈, 곱셈구구 | 곱셈·나눗셈, 분수·소수 기초 | 약수·배수, 분수·소수 사칙 | 정수·유리수·실수 | 다항식, 복소수 |
| 변화와 관계 | 규칙 찾기 | 규칙과 대응 | 비와 비율, 비례식 | 방정식, 일차·이차함수 | 함수, 수열, 지수·로그 |
| 도형과 측정 | 모양, 길이, 시계 | 각도, 평면도형, 들이·무게 | 넓이·부피, 입체도형 | 작도, 합동·닮음, 피타고라스, 삼각비 | 도형의 방정식, 기하 |
| 자료와 가능성 | 표·그래프 | 막대·꺾은선 그래프 | 평균, 가능성, 원·띠 그래프 | 통계, 확률 | 확률과 통계 |
| 미적분 | | | | | 미적분Ⅰ·Ⅱ |

## 3. 막히는 지점
| 학년 | 걸림돌 |
|---|---|
| 초2 | 받아내림, 곱셈구구 |
| 초3~4 | **분수 개념**, 긴 나눗셈 |
| 초5 | **약분·통분**, 분수 사칙 |
| 초6 | 비와 비율 |
| 중1 | 음수, 문자 사용 |
| 중2 | 일차함수 |
| 중3 | 이차함수, 인수분해 |
| 고1~2 | 추상화 급증 (함수, 수열, 미적분) |

## 4. 가정에서 할 수 있는 것
- 초저: 보드게임, 요리(분수), 쇼핑(계산), 시계 읽기
- **"어떻게 풀었어?" 설명하게 하기** (서술형·사고력)
- 틀린 문제 = 보물: 오답 이유 말로 설명

## 5. 학습지·교재·앱
- 연산 학습지(초등 저학년, 하루 10분)
- 개념서 → 유형서 → 심화서 순서
- 사고력 교구·퍼즐, 수학 동화

## 6. 체험·여행 연계
- 국립과천과학관 수학 체험, 수학문화관, 착시·퍼즐 전시
- 여행 중: 거리·시간·예산 계산 맡기기

## 7. 선행 vs 심화: 적정선
- **현행 심화 > 선행**: 현재 학년 심화 문제를 70~80% 풀 수 있을 때만 선행
- 초등: 0.5~1학기 예습 / 초5~6: 1학년 선행이 무난 (우리 집 판단)

## 8. 교육특구에서는
- 초1~3 사고력 수학 학원, 초3~4 교과 선행 전환
- 초5~6 중등 과정, 초6~중1에 고1 공통수학 진입
- 영재원·경시·과고/영재학교 트랙은 초4~5부터 준비
- **"의대반"** 등 초고속 선행반 존재 → 부담·번아웃 사례도 많음
