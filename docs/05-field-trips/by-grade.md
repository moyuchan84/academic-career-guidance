# 학년별 추천 여행

| 학년 | 주제 | 예시 |
|---|---|---|
| 초1~2 | 오감·자연 | 농촌 체험, 갯벌, 동물원, 어린이박물관 |
| 초3 | 우리 고장 | 동네 지도 만들기, 시청·소방서, 향토박물관 |
| 초4 | 우리 지역·지구 | 도 단위 여행, 지질공원, 화석 |
| 초5 | **한국사 여행** | 선사 → 삼국 → 고려 → 조선 → 근현대 순서로 |
| 초6 | 정치·경제·세계 | 국회, 한국은행, 첫 해외여행 계획 직접 짜기 |
| 중학교 | 진로·심화 | 대학 캠퍼스, 기업 견학, 테마 여행 |
| 고등학교 | 전공 탐색 | 희망 대학·학과 방문 |
