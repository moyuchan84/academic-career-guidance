# 학년별 인기 종목

| 시기 | 많이 하는 것 | 흐름 |
|---|---|---|
| 초1~2 | 태권도, 피아노, 수영, 미술, 줄넘기, 발레, 축구 | 가장 많은 종목을 경험하는 시기 |
| 초3~4 | 위 + 바이올린·플루트, 바둑, 코딩, 인라인, 농구 | 생존수영, 악기 본격 |
| 초5~6 | 축구·농구 클럽, 악기 유지, 방송댄스 | 학원 증가로 1~2개로 정리 |
| 중학교 | 스포츠클럽, 밴드·오케스트라 동아리 | 취미 또는 진학 트랙 분기 |
| 고등학교 | 동아리, 체력 관리 운동 | 학종 활동과 연계 |

## 원칙 (제안)
- **운동 1 + 예술 1** 은 초등 내내 유지
- 평생 취미가 될 **악기 1개, 운동 1개**를 초등 졸업 전 확보
- 흥미 없어하면 3개월 관찰 후 교체
