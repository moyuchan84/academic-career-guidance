학습지 비교

학습지는 "무엇을 배우느냐"보다 "매일 조금씩 하는 습관"을 만드는 도구예요. 그래서 좋은 학습지의 기준은 내용이 아니라 우리 아이와 우리 집 생활에 맞느냐입니다.

영어 말하기가 목표일 때

우리 아이에게 맞는 유형 찾기

네 가지 질문에 답하면 가장 잘 맞을 것 같은 유형을 알려 드려요. 정답이 아니라 이야기를 시작하는 출발점입니다.

1. 평일에 부모 중 한 명이 하루 15분 옆에 있어 줄 수 있나요?

2. 아이가 태블릿·영상을 약속한 때 잘 끄나요?

3. 우리 아이는 어떤 편인가요?

4. 지금 가장 원하는 것은?

네 질문에 모두 답하면 결과가 보여요.

📘 엄마표·아빠표 문제집이 잘 맞을 것 같아요. 얇은 문제집 한 권, 하루 한 쪽부터. 끝낸 날 달력에 스티커를 붙이면 루틴이 됩니다.

🧑‍🏫 방문 학습지가 잘 맞을 것 같아요. 선생님이 정해 주는 리듬이 도움이 되는 아이예요. 다만 밀렸을 때 쌓이지 않도록 분량 조절이 되는지 꼭 물어보세요.

📱 스마트 패드형이 잘 맞을 것 같아요. 흥미를 붙이는 데 좋아요. 단, 화면 시간 총량을 함께 정하고 3개월 뒤 "스스로 하는지"를 확인하세요.

🎧 화상 수업이 잘 맞을 것 같아요. 말하기가 목표라면 짧게(15~25분), 같은 선생님과 꾸준히. 체험 수업에서 아이 표정을 먼저 보세요.
