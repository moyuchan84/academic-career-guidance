# 학습지 비교

| 유형 | 장점 | 단점 | 이런 아이에게 |
|---|---|---|---|
| 방문 학습지 (선생님 주 1회) | 꾸준함, 선생님 피드백 | 밀리면 스트레스, 반복 지루함 | 루틴이 필요한 아이 |
| 스마트 패드형 | 흥미, 자동 채점·분석 | 화면 시간 증가, 수동적 | 자기주도가 약한 초저 |
| 문제집 (엄마표/아빠표) | 저렴, 속도 조절 자유 | 부모 시간·인내 필요 | 부모가 봐줄 수 있을 때 |
| 화상 수업 (영어 등) | 말하기 연습 | 집중도 편차 | 영어 말하기 |

## 고르는 기준
- [ ] 아이가 **하루 15분 안에** 끝낼 수 있는가
- [ ] 밀렸을 때 쌓이지 않는 구조인가
- [ ] 3개월 뒤 효과를 무엇으로 확인할 것인가
