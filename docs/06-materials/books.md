# 교재 로드맵

## 수학 문제집의 단계
1. **연산**: 계산 정확도·속도
2. **개념**: 교과서 수준 이해
3. **유형**: 문제 유형 연습
4. **심화**: 사고력·응용 (교육특구 아이들은 여기에 많은 시간)
5. **최상위/경시**: 선택

## 과목별 기본 세트 (초등)
| 과목 | 기본 | 추가 |
|---|---|---|
| 국어 | 독해 문제집 | 어휘·한자 |
| 수학 | 연산 + 개념/유형 | 심화 |
| 영어 | 리더스북 | 파닉스·문법 입문 |
| 사회·과학 | 교과서 + 독서 | 교과 참고서(전과) |

{: .note }
> 구입한 교재와 완료 여부를 기록해 두면 둘째에게도 도움이 됩니다.
