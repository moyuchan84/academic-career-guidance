# 학원 유형 이해

| 유형 | 특징 | 시기 |
|---|---|---|
| 공부방·교습소 | 소규모, 숙제 관리 | 초등 |
| 사고력 수학 | 교구·퍼즐·서술 | 초1~4 |
| 교과 수학 (선행·심화) | 레벨테스트, 진도반 | 초3~고 |
| 영어 어학원 | 레벨제, 원서·스피킹 | 초1~중 |
| 내신 전문 | 학교별 시험 대비 | 중·고 |
| 영재·경시·특목 대비 | 영재원, 올림피아드 | 초4~중 |
| 독서·논술 | 토론·글쓰기 | 초등 |

## 학원 선택 체크리스트
- [ ] 레벨테스트 결과를 **아이 자존감에 어떻게 전할지** 미리 합의
- [ ] 숙제량 (하루 몇 분?)
- [ ] 진도 속도 vs 이해도 확인 방법
- [ ] 그만두는 기준 (예: 3개월간 거부 지속)
