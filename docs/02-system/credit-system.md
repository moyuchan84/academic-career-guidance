# 고교학점제

## 구조
- 3년간 **192학점** 이수 (교과 174 + 창체 18)
- 고1: 공통과목 (공통국어1·2, 공통수학1·2, 공통영어1·2, 한국사1·2, 통합사회1·2, 통합과학1·2, 과학탐구실험1·2)
- 고2~3: 선택과목
  - 일반선택: 예) 대수, 미적분Ⅰ, 확률과 통계, 문학, 화법과 언어, 물리학, 화학 …
  - 진로선택: 예) 미적분Ⅱ, 기하, 역학과 에너지, 물질과 에너지 …
  - 융합선택: 예) 수학과 문화, 기후변화와 환경생태 …
- 과목 출석률·학업성취율 40% 미만 → 미이수(보충 이수)

## 부모가 할 일
- 중3~고1: 희망 전공 → **대학이 권장하는 선택과목** 확인
- 학교 교육과정 편제표 확인 (학교마다 개설 과목이 다름 → 고교 선택의 기준!)

{: .warning }
> 아이가 고등학생이 되는 2034~35년에는 운영 방식이 보완·변경되었을 가능성이 큽니다.
