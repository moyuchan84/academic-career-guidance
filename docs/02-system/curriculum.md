# 학제와 2022 개정 교육과정

## 적용 시기
| 연도 | 적용 학년 |
|---|---|
| 2024 | 초1·2 |
| 2025 | 초3·4, 중1, 고1 |
| 2026 | 초5·6, 중2, 고2 |
| 2027 | 중3, 고3 |

## 학교급별 교과 구성
| 학교급 | 교과 |
|---|---|
| 초1~2 | 국어, 수학, 바른 생활, 슬기로운 생활, 즐거운 생활 + 창의적 체험활동 |
| 초3~4 | 국어, 사회/도덕, 수학, 과학, 체육, 음악, 미술, 영어 |
| 초5~6 | 위 + **실과**(정보·코딩 포함) |
| 중학교 | 국어, 사회(역사 포함)/도덕, 수학, 과학/기술·가정/**정보**, 체육, 예술(음악/미술), 영어, 선택(한문·제2외국어 등) |
| 고등학교 | 공통과목 → 일반선택 / 진로선택 / 융합선택 (고교학점제) |

## 2022 개정의 주요 변화 (부모가 알아둘 것)
- 초1·2: 한글 해득 시간 확대, "즐거운 생활"에서 실내외 놀이·신체활동 강화
- 초·중: 정보(코딩) 교육 시간 확대
- 중학교: 자유학기 1개 학기로 축소, 중3 2학기 진로연계교육
- 고교: 고교학점제 전면 시행 (192학점)

> 세부 시수·단원은 [국가교육과정정보센터(NCIC)](https://ncic.re.kr)에서 확인합니다.
