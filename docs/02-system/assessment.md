# 학교급별 평가 방식

## 초등학교
- 지필 중간·기말고사 거의 없음 → **수행평가·서술형·관찰평가**
- 통지표: 등수가 아니라 "잘함/보통/노력 요함" 또는 서술형 문장
- 부모 포인트: 통지표 문장에서 **"노력 요함" 영역**을 찾아 조용히 보완

## 중학교
- **성취평가제 (A~E 절대평가)**, 석차 없음
- 자유학기에는 지필고사 없음
- 중2~3 내신은 특목·자사고 지원 시 반영(학교 유형별 상이)

## 고등학교
- 2025 고1부터 **5등급 상대평가** (1등급 상위 10%) + 성취도(A~E) 병기
- 수행평가 비중 높음, 학교생활기록부 "세부능력 및 특기사항(세특)"이 학종의 핵심

## 우리 집 체크

- [ ] 결과보다 "무엇을 배웠는지" 먼저 묻기
