# 대입 제도

## 전형의 큰 틀
| 구분 | 전형 | 핵심 |
|---|---|---|
| 수시 | 학생부교과 | 내신 등급 |
| 수시 | 학생부종합(학종) | 세특·활동·면접, "성장 스토리" |
| 수시 | 논술 | 대학별 논술 + 수능 최저 |
| 수시 | 실기/특기 | 예체능, 어학·수학 특기 등 |
| 정시 | 수능 위주 | 수능 점수, 일부 대학 교과 반영 |

## 2028학년도 대입 개편 (2025년 고1부터)
- 수능 선택과목 폐지 → 국어·수학 **공통 응시**
- 수학 범위: 대수, 미적분Ⅰ, 확률과 통계
- 탐구: **통합사회·통합과학** 모두 응시
- 영어·한국사: 절대평가 유지
- 내신: 5등급제

## 우리 아이 세대 (2036~2037 수능) 전망
- 지금 제도가 그대로일 거라고 가정하지 않기
- 변하지 않을 것: **읽기 능력, 수학적 사고, 영어, 꾸준히 공부하는 습관**
- → 초등 시기는 제도 대비가 아니라 **기초 체력** 만들기
