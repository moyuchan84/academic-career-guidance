# 중학교 2학년
{: .no_toc }

1. TOC
{:toc}

## 1. 한눈에 보기
**'중2' 사춘기 · 수학 핵심 단원 · 고교 방향 탐색**

## 2. 발달 특성
- 정서 기복 최대, 부모와 갈등 정점
- 논리적 사고 크게 성장

## 3. 이 학년에 배우는 것
| 과목 | 주요 내용 |
|---|---|
| 수학 | 유리수와 순환소수, 식의 계산, 일차부등식, 연립방정식, **일차함수**, 삼각형·사각형의 성질, 닮음, 피타고라스 정리, 확률 |
| 과학 | 물질의 구성, 전기와 자기, 태양계, 식물과 에너지, 동물과 에너지 등 |
| 영어 | 문법 심화, 긴 독해 |
| 역사 | 한국사·세계사 |

## 4. 부모의 역할: 이것만은 함께
- 잔소리 줄이고 **규칙은 적게, 대신 확실하게**
- 고교 유형 탐색 시작 ([중·고등학교 진학](../09-school-choice/) 참고)
- 특목·자사고 목표면 중2 내신부터 반영됨 → 확인

## 5. 흔한 어려움과 대처
| 어려움 | 대처 |
|---|---|
| 함수 개념 | 그래프로 생활 현상 표현 (요금제 비교) |
| 공부 거부 | 목표를 아이 스스로 세우게, 부모는 환경만 |
| 게임 과몰입 | 시간보다 '끝내는 방법' 합의 |

## 6. 추천 체험·여행
- 관심 분야 대학 학과 체험, 박람회
- 해외 진학 고려 시: 해외 캠프·단기 연수 탐색

## 7. 학습지·교재
- 내신 대비 문제집, 기출
- 비문학 독서 꾸준히 (고등 국어 대비)

## 8. 예체능·특기
- 운동으로 스트레스 해소, 악기는 취미로

## 9. 선행·심화: 적정선
- 교육특구: 고등 수학 선행 2~3회독 (미적분까지), 고1 국어·과학 선행
- 우리 집 기준안: 중2 함수 완벽 + 고1 공통수학 심화

## 10. 부부 체크리스트
- [ ] 학기 초: 담임 상담 신청, 올해 목표 1~2개 합의
- [ ] 매월: 공부 정서 점검 ("요즘 공부 어때?" 1~5점)
- [ ] 학기 말: 통지표 함께 읽기, 사교육·예체능 유지/중단 결정
- [ ] 방학 전: 방학 계획 (체험 1회 이상, 푹 쉬는 주 1주 이상)
