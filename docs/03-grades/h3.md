# 고등학교 3학년
{: .no_toc }

1. TOC
{:toc}

## 1. 한눈에 보기
**수시 원서 · 수능 · 정시 · 새로운 시작**

## 2. 발달 특성
- 극도의 긴장, 부모의 역할은 "든든한 배경"

## 3. 이 학년에 배우는 것
| 시기 | 일정 |
|---|---|
| 3~6월 | 모의고사, 1학기 내신 (수시 반영 마지막) |
| 6월 | 평가원 모의평가 |
| 9월 | 평가원 모의평가, **수시 원서 접수 (6장)** |
| 11월 | **수능** |
| 12월~ | 수시 발표, 정시 원서 (가·나·다군) |

## 4. 부모의 역할: 이것만은 함께
- 원서 전략은 **데이터 기반 + 아이 의사 존중**
- 식사·수면·건강 관리, 불안한 말 줄이기
- 결과와 상관없이 "수고했다"

## 5. 흔한 어려움과 대처
| 어려움 | 대처 |
|---|---|
| 수능 불안 | 실전 루틴 연습(수능 시간표대로 모의) |
| 원서 갈등 | 입시 상담(학교 진학부) 함께 가기 |

## 6. 추천 체험·여행
- 수능 후: 가족 여행, 대학 생활 준비

## 7. 학습지·교재
- 수능 기출·EBS 연계, 대학별 논술·면접 기출

## 8. 예체능·특기
- 스트레칭·산책 수준 유지

## 9. 선행·심화: 적정선
- 해당 없음. 수능 후 대학 과정 예습은 선택

## 10. 부부 체크리스트
- [ ] 학기 초: 담임 상담 신청, 올해 목표 1~2개 합의
- [ ] 매월: 공부 정서 점검 ("요즘 공부 어때?" 1~5점)
- [ ] 학기 말: 통지표 함께 읽기, 사교육·예체능 유지/중단 결정
- [ ] 방학 전: 방학 계획 (체험 1회 이상, 푹 쉬는 주 1주 이상)
