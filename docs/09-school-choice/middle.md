# 중학교 유형

| 유형 | 특징 | 선발 |
|---|---|---|
| 일반 중학교 | 대부분, 근거리 배정 | 추첨 배정 |
| 국제중학교 | 영어 몰입·국제 교육 (서울·경기 등 소수) | 서류·면접·추첨 |
| 예술중 | 음악·미술·무용 | 실기 |
| 체육중 | 체육 특기 | 실기 |
| 대안학교 | 인가·비인가 | 학교별 |
| 외국인학교·국제학교 | 해외 거주 요건 등 제한 | [해외 진학 트랙](../10-overseas/) |

{: .warning }
> 국제중 지정·운영 여부는 정책에 따라 변동됩니다. 초5에 최신 모집요강을 확인합니다.
